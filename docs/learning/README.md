# Learning Notes

One short note per phase, written at the end of it, in the owner's words with the assistant's help. The point is to keep what was learned, not to restate the code.

File name: `phase-NN-topic.md`, e.g. `phase-02-run-state-machine.md`.

## Template

```markdown
# Phase NN: Topic

## Read beforehand
The reading for this phase, and the one idea from it that mattered most.

## Concepts
The ideas this phase was really about, each in a sentence or two.

## Decisions and why
Each choice made, the alternatives, and what tipped it. Link the ADR if there is one.

## Mistakes and surprises
What went wrong or behaved unexpectedly, and what that taught.

## How it would differ at a company
What a production team would do differently at scale.

## Open questions
What's still unclear, to revisit later.
```
